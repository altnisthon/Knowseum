# Knowseum

A gamified news museum for young readers in Singapore.

- **`index.html`**: sends visitors straight to the app.
- **`old/`**: the earlier web build (still playable at `/old/`).
- **`app/`**: the mobile app prototype (lobby, wing rooms, interactive stories, Perspectives, quizzes, passport, map and Hall of Fame). See [`app/README.md`](app/README.md) for how to run it, play it online and work on it together.
